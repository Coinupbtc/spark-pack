121 GB is per Spark, not a shared pool. A 2-Spark cluster is two 121 GB tanks. DS4F in TP2 puts about 79 GB of weights on each rank — that is why the live pair looks full, not half empty.

What this is for

sparkfit answers “does this one model fit?” Mia’s recipes start the model. This answers the weekly question: can these residents share a box without a hard reboot.

H3 + DS4F is the measured kill combo (89.4 GB on Spark 1). Vision 4B can sit on Spark 2 beside the cluster. A 9B vision TP2 under DS4F cannot. Docker stats will lie about unified memory — believe free and these dated sizes.

The catalog will not start or stop anything. ./probe.sh only reads free, listening ports, and docker names, then writes probe.json.
